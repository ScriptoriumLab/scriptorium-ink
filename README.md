# Modian Ink

This project implements Modian IME candidate UI by using Tauri and Typescript.

This candidate UI is a macOS style UI.

## How to run

You must follow the instruction of Tauri to install `Rust` and `Nodejs` and `pnpm`, so that you can install `Tauri` in cargo. I'll add more details about how to install these frameworks later.

After you can use `Rust` and `pnpm`, you can just run `pnpm tauri dev` to run this application.
